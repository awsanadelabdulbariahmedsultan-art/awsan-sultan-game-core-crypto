# 🎮 Crypto-Game Engine powered by NVIDIA RTX Spark & Web3

An advanced, highly-scalable, cross-platform Web3 Gaming Engine designed to bridge next-generation graphical technologies with decentralized economies. This engine compiles seamlessly across **all Mobile devices, PlayStation, Xbox, and high-end PCs**.

## ✨ Key Features
* **Hybrid Graphical Pipeline:** Dynamic hardware scaling featuring full Path Tracing and NVIDIA DLSS for PC/Consoles, alongside highly-optimized shaders for mobile devices.
* **Local AI via RTX Spark:** Utilizing NVIDIA ACE SDK to run intelligent, context-aware NPCs locally on player hardware without high cloud costs.
* **Secure Web3 Ecosystem:** Built-in SHA256 cryptographic signatures, stable node connections, cold storage safety, and automated $AST token and XP distributions for PvP matchmaking.
* **Cross-Platform Play:** Optimized latency via NVIDIA Reflex ensuring balanced competitive play between PC, mobile, and console gamers.

## 📁 Repository Structure
* `/game-client`: Main game project files (Unreal Engine 5 / Unity).
* `/blockchain-core`: Smart contracts for $AST tokens, staking, and XP metadata.
* `/assets`: Exclusively generated high-fidelity artworks from the *Awsan Sultan Art (ASA)* gallery.
